## Layout

- `spec.yaml`: the build contract. Source of truth for intent.
- `network/`: TDXN export, readable and diffable. Source of truth for structure.
- `scripts/`: externalized Python, edited directly by the agent.
- `glsl/`: externalized shaders.
- `captures/`: timestamped visual evidence for every build.
- `project.toe`: binary, regenerable from the TDXN.
